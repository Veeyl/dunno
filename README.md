# Brew & Bite POS

A modern, responsive Point of Sale (POS) frontend built with **Vue 3** (`<script setup>`), **Vite**, **Tailwind CSS**, **Pinia**, **Vue Router**, and **Chart.js** (`vue-chartjs`). Runs entirely in the browser with mock data persisted to `localStorage`.

## Quick start

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `/` | Focus the product search box (POS) |
| `Enter` | Open checkout (or add product when search has 1 match) |
| `Esc` | Close dialogs / clear search |
